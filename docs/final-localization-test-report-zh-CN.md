## 四、已知限制

| 限制 | 说明 |
|------|------|
| 语言切换需重启 | 不支持实时切换，需重启程序生效 |
| HotKeyAction 枚举值 | 内部值仍为英文（Open、Duplicate 等），仅界面显示中文 |
| 品牌名保留英文 | GitHub Sponsors、Patreon 等保留英文 |
| 安装器未汉化 | Inno Setup 脚本仍为英文 |
