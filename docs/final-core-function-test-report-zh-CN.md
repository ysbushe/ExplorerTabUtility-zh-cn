## 二、需求 B：资源管理器空白处双击向上一级

### 2.1 测试配置

| 设置项 | 值 |
|--------|-----|
| Mouse Hook | 需手动启用 |
| 快捷键配置 | 鼠标左键双击 + NavigateUp + FileExplorer |

### 2.2 测试用例

| # | 测试场景 | 预期结果 | 状态 | 实际现象 |
|---|----------|----------|------|----------|
| 1 | 双击文件列表空白处 | 返回上一级目录 | ⏳ 待验证 | |
| 2 | 进入多级目录后双击空白处 | 返回上一级目录 | ⏳ 待验证 | |

### 2.3 误触发测试

| # | 测试场景 | 预期结果 | 状态 | 实际现象 |
|---|----------|----------|------|----------|
| 3 | 双击文件夹 | 正常打开文件夹，不触发向上一级 | ⏳ 待验证 | |
| 4 | 双击文件 | 正常打开文件，不触发向上一级 | ⏳ 待验证 | |
| 5 | 双击地址栏 | 编辑路径，不触发向上一级 | ⏳ 待验证 | |
| 6 | 双击侧边栏 | 无误触发 | ⏳ 待验证 | |
| 7 | 双击标题栏 | 最大化/还原，不触发向上一级 | ⏳ 待验证 | |
| 8 | 右键空白处 | 弹出右键菜单，不触发向上一级 | ⏳ 待验证 | |

### 2.4 配置步骤

1. 双击托盘图标打开设置窗口
2. 点击"新建"添加配置
3. 快捷键输入框中**双击鼠标左键**（显示 LMB_DBL）
4. 作用范围选择"资源管理器内"（FileExplorer）
5. 动作选择"向上一级"（NavigateUp）
6. 点击"保存"
7. 右键托盘 → 启用"鼠标监控"

由于当前环境为 CLI 终端，无法直接观察 GUI 界面。以下测试项需要用户在本机手动执行：

1. **启动程序**：双击 `D:\Test\ExplorerTabUtility.exe`
