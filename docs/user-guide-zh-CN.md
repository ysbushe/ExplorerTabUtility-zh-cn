# ExplorerTabUtility 使用说明

> 适用于 Windows 11（版本 22H2 及以上）
> 版本：2.5.0

---

## 简介

ExplorerTabUtility 是一款 Windows 11 文件资源管理器增强工具。它的核心功能是**将新打开的资源管理器窗口自动转换为标签页**，让您像使用浏览器一样管理文件夹，告别杂乱的多窗口桌面。

---

## 安装

### 方法一：使用 winget（推荐）

打开 PowerShell 或命令提示符，运行：

```powershell
winget install w4po.ExplorerTabUtility --interactive
```

### 方法二：使用 Chocolatey

```powershell
choco install explorertabutility --params "/interactive"
```

### 方法三：手动安装

1. 从 [GitHub Releases](https://github.com/w4po/ExplorerTabUtility/releases) 下载最新版本
2. 运行安装程序
3. 按照提示完成安装

### 方法四：便携版

1. 下载便携版 ZIP 文件
2. 解压到任意目录
3. 双击运行 `ExplorerTabUtility.exe`

## 快速上手

### 启动程序

安装完成后，程序会在系统托盘（任务栏右下角）显示一个图标。

- **双击托盘图标** → 打开设置窗口
- **右键托盘图标** → 打开快捷菜单

### 核心功能：新窗口自动变标签页

**默认已启用！** 您只需要：

1. 确认托盘图标已显示
2. 右键托盘图标，确保 **窗口监控** 和 **复用标签页** 已勾选
3. 正常使用资源管理器，新打开的窗口会自动变为标签页

**效果演示：**
- 双击文件夹 → 不再弹出新窗口，而是在当前窗口中打开新标签页
- 已打开的路径再次打开 → 自动切换到已有标签页，不会重复打开

### 强制打开新窗口

按住 **Ctrl + Shift** 再打开路径，可以临时绕过标签页功能，强制打开新窗口。

## 快捷键配置

### 默认快捷键

| 快捷键 | 功能 | 说明 |
|--------|------|------|
| Win + E | 打开主页 | 打开资源管理器默认位置 |
| Ctrl + D | 复制标签页 | 复制当前标签页 |
| Shift + Ctrl + T | 重开已关闭 | 重新打开最近关闭的标签页 |

### 添加自定义快捷键

1. 双击托盘图标打开设置窗口
2. 在"快捷键"页面点击 **新建**
3. 配置以下选项：
   - **名称**：给配置起个名字
   - **快捷键**：点击输入框，按下想要的键组合
   - **作用范围**：选择"全局"或"资源管理器内"
   - **动作**：选择要执行的操作
4. 点击 **保存**

### 可用动作

| 动作 | 说明 |
|------|------|
| 打开 | 打开指定路径（文件夹、文件、网址） |
| 复制标签页 | 复制当前标签页 |
| 重开已关闭 | 重新打开最近关闭的标签页 |
| 标签页搜索 | 打开标签页搜索弹窗 |
| 后退 | 向后导航 |
| 前进 | 向前导航 |
| 向上一级 | 向上一级目录 |
| 设为目标窗口 | 设置接收新标签的窗口 |
| 分离标签页 | 将当前标签页分离为新窗口 |
| 贴靠窗口 | 将窗口贴靠到屏幕边缘（上/下/左/右） |
| 切换窗口监控 | 开关窗口监控功能 |
| 切换复用标签页 | 开关标签页复用功能 |
| 显示/隐藏主窗口 | 切换设置窗口的可见性 |

### 鼠标快捷键

除了键盘快捷键，还可以配置鼠标操作：

1. 在快捷键输入框中**双击鼠标左键**
2. 输入框会显示 `LMB_DBL`
3. 配置动作（如"向上一级"）
4. 保存后，在资源管理器空白处双击即可触发

## 高级功能

### 标签页搜索

按配置的快捷键（默认未配置）打开标签页搜索弹窗：

- 输入文件夹名称或路径进行搜索
- 上下箭头选择，回车确认
- 按 **Shift** 打开为新窗口
- 按 **Ctrl** 复制标签页
- 点击清除按钮可清空已关闭窗口历史

### 分离与贴靠

可以组合使用分离和贴靠功能，实现高效的窗口布局：

1. 创建一个快捷键配置：分离标签页
2. 创建第二个快捷键配置：贴靠到左侧（设置适当延迟）
3. 创建第三个快捷键配置：贴靠到右侧（设置适当延迟）

按一次快捷键即可完成：分离 → 左侧贴靠 → 右侧贴靠。

### 恢复上次窗口

在偏好设置中启用 **恢复上次窗口**，程序会在以下情况自动恢复之前打开的窗口：

- 资源管理器崩溃后重启
- 系统重启后首次启动

### 保存已关闭历史

在偏好设置中启用 **保存已关闭历史**，可以在重启程序后仍然使用"重开已关闭"功能。

| 我有主题兼容问题 | 使用替代的窗口隐藏方法 | 关闭 |

| 隐藏托盘图标 | 隐藏系统托盘图标 | 关闭 |

## 常见问题

### Q：程序启动后没有托盘图标？

A：检查是否已有实例在运行。如果托盘图标被隐藏，可以通过配置的快捷键（需先设置"显示/隐藏主窗口"动作）重新显示。

### Q：新窗口没有自动变为标签页？

A：请确认：
1. 右键托盘图标，"窗口监控"是否已勾选
2. "复用标签页"是否已勾选
3. 是否按住了 Ctrl+Shift（这会强制打开新窗口）

### Q：双击空白处没有向上一级？

A：请确认：
1. 已添加鼠标快捷键配置（双击左键 + NavigateUp 动作）
2. 作用范围选择"资源管理器内"
3. 右键托盘图标，"鼠标监控"是否已勾选

### Q：杀毒软件报警？

A：程序使用了低级键盘/鼠标钩子，可能触发误报。这是正常现象，可以将程序添加到杀毒软件白名单。

### Q：如何完全卸载？

A：
1. 如果通过 winget 安装：`winget uninstall w4po.ExplorerTabUtility`
2. 如果通过安装程序：使用 Windows 设置 → 应用 → 卸载
3. 删除设置文件夹：%APPDATA%\ExplorerTabUtility
